sven has no type system of its own. A type is any value with `check = value: bool`.
`lib.types` from nixpkgs works, a kind works (see [Instances and refs](/concepts/instances-refs/)),
and `sven.lib.is` makes a type from any function.


| Constructor | Default |
|---|---|
| `lib.types.str`, any type | none: the field is required |
| `sven.lib.opt type value` | `value` |
| `sven.lib.maybe type` | `null` |
| `sven.lib.derive type (self: …)` | computed from the instance itself |
| `sven.lib.is (v: …)` | none: a type from a check function |

```nix title="modules/host.nix" {9-14}
# A type is anything with `check = value: bool`. sven adds defaults on top of it.
{ sven, lib, ... }:
let
  inherit (sven.lib) opt maybe derive is;
in
{
  sven.kinds.host.fields = {
    addr = lib.types.str;                                  # required
    port = opt lib.types.port 22;                          # a default
    jump = maybe lib.types.str;                            # null by default
    vpn = derive lib.types.str (self: "vpn-${self.name}"); # a default computed from the instance
    tags = opt (is (v: lib.isList v && lib.all lib.isString v)) [ ]; # your own check
    settings.kernel.channel = opt (lib.types.enum [ "lts" "latest" ]) "lts"; # nested fields
  };
}
```

Fields can nest. `settings.kernel.channel` is one field at a path, with its own type and default.
An instance gives only what it needs:


```nix title="modules/hosts.nix"
{ sven, ... }:
{
  sven.host.web.addr = "10.0.0.1";
  sven.host.db = {
    addr = "10.0.0.2";
    port = 2222;
    vpn = "vpn-database"; # an explicit value wins over `derive`
    settings.kernel.channel = "latest";
  };
}
```

The read of a field looks at the instance first, then at the default, then checks the value:


```nix title="result"
{
  db = {
    channel = "latest";
    jump = null;
    port = 2222;
    tags = [ ];
    vpn = "vpn-database";
  };
  web = {
    channel = "lts";
    jump = null;
    port = 22;
    tags = [ ];
    vpn = "vpn-web";
  };
}
```

:::note[Derived defaults]
`derive` gets the instance as `self`, so a default can read other fields or the instance name.
An explicit value always wins: `db` sets its own `vpn`.
:::
