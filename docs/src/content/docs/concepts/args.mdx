An element can be a function with named args. sven fills the args it knows:


| Arg | Value |
|---|---|
| a kind name (`host`, `environment`) | the nearest ancestor-or-self scope of that kind |
| a sink name (`backends`) | the reduced value of that sink at its nearest receiver |
| `scope` | the scope itself |
| anything else (`pkgs`, `config`) | stays open: the element is still a function |

A load balancer reads the addresses that its environment collects:


```nix title="modules/fleet.nix"
{ sven, lib, ... }:
let
  under = s: lib.filterAttrs (_: h: sven.lib.same h.environment s) sven.host;
in
{
  sven.kinds.fleet = {
    spawns.environment = _: sven.environment;
    sinks.out.reduce = sven.lib.reduce.merge;
  };
  sven.kinds.environment = {
    spawns.host = under;
    sinks.backends = { }; # hosts give their address; a wall: it stays at the environment
  };
  sven.kinds.host = {
    fields = { environment = sven.kinds.environment; addr = lib.types.str; };
    sinks.proxy.out = { host, proxy, ... }: { proxy.${host.name} = proxy; };
  };

  sven.kinds.cluster.fields = { }; # a kind that no scope here is under

  sven.fleet.main = { };
  sven.environment.prod = { };
  sven.host.lb = { environment = sven.environment.prod; addr = "10.0.0.1"; };
  sven.host.web-1 = { environment = sven.environment.prod; addr = "10.0.0.2"; };
  sven.host.web-2 = { environment = sven.environment.prod; addr = "10.0.0.3"; };
  sven.flake = { out, ... }: out;
}
```

```nix title="modules/aspects.nix" {5,10}
{ sven, ... }:
{
  sven.aspects.backend = {
    at = sven.lib.all [ sven.kinds.host (s: s.name != "lb") ];
    backends = { host, ... }: host.addr; # a kind arg: the nearest host
  };
  sven.aspects.balancer = {
    at = sven.host.lb;
    # a sink arg: the reduced value at its nearest receiver (the environment);
    # `scope` is the scope itself; `cluster ? null` is optional, and this fleet has no cluster
    proxy = { environment, backends, scope, cluster ? null, ... }: {
      inherit backends;
      at = scope.id;
      env = environment.name;
      cluster = if cluster == null then "none" else cluster.name;
    };
  };
}
```

```nix title="result"
{
  lb = [
    {
      at = "fleet:main/environment:prod/host:lb";
      backends = [
        "10.0.0.2"
        "10.0.0.3"
      ];
      cluster = "none";
      env = "prod";
    }
  ];
}
```

## Optional and missing args

`{ cluster ? null, ... }` makes an arg optional. Without a default, an arg with no answer means the element
is not given, and `errors` says why:


```nix title="variants/missing.nix"
# `cluster` without a default: no answer at lb, so the element is not given.
{ sven, ... }:
{
  sven.aspects.cluster-name = {
    at = sven.host.lb;
    proxy = { cluster, ... }: cluster.name;
  };
}
```

```nix title="result"
[
  {
    class = "fixable";
    code = "error";
    error = "aspect cluster-name: arg `cluster` has no answer";
    from = "fleet:main/environment:prod/host:lb";
    path = [ ];
  }
]
```

## Open args: modules for NixOS and home-manager

Args that sven does not know stay open. This is how a `nixos` element is a NixOS module: sven fills `host`,
and NixOS fills `pkgs`, `config` and `lib` later.


```nix title="variants/open.nix"
# `pkgs` is not a kind, a sink or `scope`: it stays open. The element is a module function.
{ sven, ... }:
{
  sven.aspects.open = {
    at = sven.host.lb;
    proxy = { host, pkgs, ... }: { name = host.name; shell = pkgs.bash; };
  };
}
```

:::caution[Overlays]
A bare `final: prev:` is a function of `final`, and sven has no `final`. That is an error.
Wrap it: `{ ... }: final: prev: …`.
:::
